# TikTok Auto Publisher

A desktop application designed to simplify the process of publishing video clips to TikTok from a local folder.

## Overview

TikTok Auto Publisher allows users to connect their TikTok account, select a local folder containing video clips, and publish videos through TikTok.

The application can automatically scan the selected folder and detect recently added videos, making it easier to manage and publish new content without manually selecting each file.

## Features

* Connect a TikTok account
* Select a local folder containing video clips
* Automatically scan the folder for recently added videos
* Detect new videos added to the folder
* Manage videos ready for publication
* Publish video clips to TikTok
* Simple desktop interface

## How It Works

### 1. Connect Your TikTok Account

The user connects their TikTok account through the official TikTok authorization process.

The application requests only the permissions required for its TikTok functionality.

### 2. Select a Video Folder

The user selects a folder on their computer where video clips are stored.

### 3. Automatic Folder Scanning

The application periodically scans the selected folder and checks for recently added video files.

When a new video is detected, it can be added to the application's publishing workflow.

### 4. Publish Videos

The user can manage the detected videos and publish them to TikTok through the supported TikTok API integration.
